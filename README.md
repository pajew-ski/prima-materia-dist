# prima-materia-dist

Auto-generated mirror. **Do not edit anything here by hand.** Every file is
overwritten on each push to `main` of the source repository, and a manual
change is lost without a trace.

## This is not the address

The identifiers in this ontology resolve to <https://pajew.ski/prima-materia/>.
That host carries the same serialisations, plus `llms.txt` and the
independently loadable parts under `parts/`. This mirror exists for consumers
that prefer to load from jsDelivr; it carries the complete serialisations and
nothing else.
